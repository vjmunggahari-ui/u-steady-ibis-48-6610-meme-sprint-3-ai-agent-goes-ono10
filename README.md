## Run it

```sh
node main.ts
```

`main.ts` copies the build-time-rendered `entry.png` (1024×1024, 380,261 bytes) into `$MAKEFUN_OUTPUT_DIR` (or `./output`) and verifies it: PNG signature, size ≤ 1 MiB, dimensions ≤ 1024×1024, and a byte-identical read-back with matching sha256. No network is used at runtime.
